# Theme Studio — محرر واجهات شاشة السيارة (Pioneer Y6 HZ25 · 1024×600)

إضافة كاملة على Open Launcher: محرر تصميم حقيقي داخل التطبيق، والتصميم يشتغل كواجهة رئيسية فعلية على شاشة السيارة.

## نقاط الدخول
| المكان | ماذا يفتح |
|---|---|
| زر **Design** (أيقونة الفرشاة) في الشريط الجانبي للانشر | المحرر بملء الشاشة |
| أيقونة **Theme Studio** في قائمة التطبيقات | المحرر كتطبيق مستقل (مناسب للتابلت دون جعل اللانشر واجهة التابلت) |
| ضغطة مطولة على أي فراغ في تصميم مفعّل | قائمة: تعديل التصميم / كل التطبيقات / الإعدادات / الواجهة الكلاسيكية |

## ما يدعمه المحرر
- **العناصر:** نص، مستطيل، دائرة، خط، صورة من الجهاز، أيقونة (53 أيقونة)، ساعة حية، تاريخ، اختصار تطبيق.
- **التحكم باللمس والماوس:** ضغطة = تحديد · سحب = تحريك · 8 مقابض = تغيير العرض/الارتفاع · المقبض العلوي = تدوير (يلتقط كل 15°) · إصبعان على عنصر محدد = تكبير/تصغير · إصبعان على الفراغ أو عجلة الماوس = تقريب اللوحة · سحب الفراغ = تحريك اللوحة.
- **لوحة المفاتيح (تابلت/ماوس):** الأسهم = تحريك 1px (مع Shift = 10px) · Ctrl+Z / Ctrl+Y · Ctrl+D تكرار · Ctrl+S حفظ · Delete حذف · Esc إلغاء التحديد.
- **الخصائص:** X/Y/عرض/ارتفاع رقمياً، حفظ النسبة، تدوير، شفافية، تعبئة لون/تدرج/بدون، إطار وسماكته، استدارة الزوايا، ظل/توهج، لون الأيقونة، ألوان مع شفافية.
- **الخطوط:** خط النظام (يدعم العربية)، Serif، Mono، JetBrains Mono، Source Code Pro، أو **استيراد أي خط TTF/OTF** (مثل خط اسمك). حجم، عريض، مائل، محاذاة، تباعد حروف.
- **الطبقات (Layers):** قائمة بالترتيب من الأعلى، إظهار/إخفاء، قفل، إعادة تسمية، أسهم أعلى/أسفل، وضغطة مطولة + سحب لإعادة الترتيب.
- **أدوات:** محاذاة على اللوحة (6 اتجاهات)، شبكة قابلة للإظهار، التقاط للشبكة، أدلة ذكية لحواف ومراكز العناصر، تراجع/إعادة (150 خطوة)، تكرار.
- **الخلفية:** لون، تدرج بزاوية، أو صورة (ملء/احتواء/تمديد) مع تعتيم.
- **المشاريع:** حفظ تلقائي بعد 4 ثوانٍ من آخر تعديل + زر حفظ، قائمة مشاريع بصور مصغرة، فتح/نسخ/حذف، 4 قوالب (فارغ، داكن كلاسيكي، ذهبي فاخر، نيون أزرق).
- **التصدير:** PNG بدقة 1024×600 بالضبط (أو ×2) إلى `Pictures/OpenLauncher`، مشاركة الصورة، وتصدير/استيراد ملف `.oltheme` (zip يحوي التصميم وصوره وخطوطه) للنسخ الاحتياطي أو نقل التصميم بين التابلت والسيارة.
- **معاينة واقعية:** محرك رسم واحد يُستخدم في المحرر وفي PNG وفي التشغيل، فما تراه هو الناتج نفسه. زر 100% يعرض بكسل مقابل بكسل.

## التشغيل على شاشة Pioneer Y6 HZ25
لم يُفترض أن النظام يدعم تثبيت ثيمات خارجية. التطبيق نفسه **Launcher (HOME)**، لذلك:
1. ثبّت الـ APK على الشاشة واختر Open Launcher كواجهة رئيسية ("دائماً").
2. في المحرر ← تبويب **اللوحة** ← **تفعيل كواجهة رئيسية**.
3. الواجهة تعرض تصميمك بملء الشاشة؛ الساعة والتاريخ يتحدثان، والاختصارات تفتح التطبيقات الحقيقية.
4. زر **فحص الجهاز والشاشة** يعرض الدقة الفعلية، إصدار أندرويد، الشركة، اللانشرات المثبتة، حزم الشركة (مثل szchoiceway/FYT)، وهل يوجد مدير ثيمات — للتأكد من الجهاز بدل الافتراض.

إذا كانت دقة الجهاز ليست 1024×600 يُعرض التصميم بتحجيم يحافظ على النسبة.

## البنية البرمجية
```
designer/
  model/      DesignModel, DesignOps, History, DesignJson, DesignTemplates   ← Kotlin خالص، مُختبر
  render/     DesignRenderer (android.graphics), DesignIcons
  data/       DesignRepository (ملفات + .oltheme + PNG), DeviceCheck
  ui/         DesignerScreen, DesignCanvas, PropertiesPanel, LayersPanel, CanvasPanel,
              DesignerDialogs, DesignHomeScreen (التشغيل), DesignerControls
  DesignerViewModel.kt, DesignerActivity.kt
```
الملفات تُحفظ في `files/designs/<id>/design.json` مع مجلد `assets/` وصورة مصغرة `thumb.png`.

## البناء والاختبار
```bash
./gradlew testDebugUnitTest   # اختبارات محرك التصميم
./gradlew assembleDebug       # APK في app/build/outputs/apk/debug/
```
أو تلقائياً عبر GitHub Actions (`.github/workflows/build-apk.yml`) — الـ APK يظهر في Artifacts لكل تشغيل.
